# 默认画面风格：抖音直播机构版 Fluent 产品宣传片

本文件是默认预设，不是灵感参考。用户未指定其他风格时必须执行。

## 1. 视觉原则

- 真实录屏、截图和 GIF 是视觉真相，保留原 UI 布局、表格层级、卡片结构、字体比例、入口位置和产品配色。
- 整体为 Microsoft Fluent 风格：蓝白渐变、亚克力半透明表面、柔和层叠光影、企业级生产力工具质感。
- 不重新设计成抽象科技 dashboard，不生成虚构数据、按钮、粒子、霓虹网格或赛博界面。
- 镜头固定中心构图。无无意义推拉、摇移、三维旋转或频繁切镜；运动主要发生在 UI 主体内部。
- 页面切换必须等配音讲完；关键结果页要留出阅读时间。

## 2. 默认画布

以 1920×1080、30fps 为基准，其他画幅等比例适配：

- 背景：`linear-gradient(135deg, #EDF4FF 0%, #F8FBFF 52%, #E8F1FF 100%)`
- 可在右上、左下加入低透明蓝色径向柔光，禁止抢画面。
- 可加入极淡网格，透明度不超过 `.26`，仅用于增加层次。
- 页面外边距建议：横向 `80px`、顶部 `78px`、底部为字幕预留约 `120px`。

## 3. UI 主体框架

- UI/录屏容器优先占画面宽度的 88%–92%，让用户看得清真实页面。
- 基准容器：`1760×876px`，圆角 `28px`。
- 表面：`rgba(248,251,255,.92)`。
- 描边：`1px solid rgba(255,255,255,.95)`。
- 阴影：`0 34px 90px rgba(40,88,158,.18), 0 10px 26px rgba(63,109,180,.10)`。
- 录屏和截图保持原比例，优先 `object-fit: contain`；不得为了铺满而裁掉导航、页签、表头或关键按钮。
- 需要局部放大时，只放大真实 UI 区域，放大结束后平滑回到全局页面。

## 4. 标题与字幕

- 字体：`PingFang SC, Microsoft YaHei, sans-serif`。
- 主标题使用深蓝 `#123A72`，强调词使用 `#3378F6`。
- 底部字幕采用亚克力胶囊或短卡片，居中放置，不遮挡 UI：
  - 字号基准 `27px`
  - 字重 `590`
  - 背景 `rgba(247,251,255,.92)`
  - 圆角 `20px`
  - 描边 `1px solid rgba(255,255,255,.98)`
  - 阴影 `0 14px 42px rgba(39,83,148,.14)`
- 屏幕文案只保留核心结论，不把整段配音逐字堆在画面上。

## 5. 动效与转场

- 进入：`0.35–0.6s`，使用轻微淡入、`y: 12–24px` 或 `scale: .96–.99`。
- 强调：蓝色聚焦线、短促高亮、局部轻微放大；避免大幅弹跳。
- 页面转场：`0.4–0.7s`，使用柔和淡化、亚克力遮罩、clip reveal 或同构元素衔接。
- 动效缓动优先：`power3.out`、`power3.inOut`、克制的 `back.out(1.2–1.4)`。
- 转场期间不能提前清空上一页；新页面稳定后再开始讲下一功能。
- 所有动效必须确定性执行，不使用随机粒子或无限循环。

## 6. 默认节奏

- 开场能力发布：约 `2–4s`。
- 单个简单入口：约 `1.2–2.2s`。
- 两到三步操作：约 `3–6s`。
- 复杂结果或 AI 总结：结果完整出现后至少停留 `2.5–4s`。
- 最后业务提醒或行动号召：约 `2–4s`。
- 品牌结束页：固定 `2s`。

配音是时间轴基准。先生成分段配音、读取实际时长，再安排画面；禁止先压缩画面后强塞配音。

## 7. 点击高亮

默认关闭。用户明确要求并提供圈选关键帧或坐标后才启用，具体遵守 `SKILL.md`。

点击高亮关闭不代表音效关闭：真实录屏中清晰可见的关键点击，可以使用克制的 UI 点击音效。

## 8. 禁止项

- 不把截图放进倾斜悬浮的 3D 设备阵列。
- 不使用深色赛博背景、粒子雨、发光电路和无关机器人形象。
- 不用大型营销卡片长期盖住真实 UI。
- 不在页面尚未看清时连续跳转。
- 不让字幕、水印或装饰覆盖关键表格、按钮和 AI 总结内容。
